# AI CivicSense — Urban Civic Issue Reporting & Management Platform

AI-powered civic governance and real-time grievance reporting system with automated YOLO-based visual defect detection, automated SLA priority scoring, and department-scoped municipal triage dashboards.

## Architecture
- **ai-service**: FastAPI, YOLO defect detection & classification pipeline
- **civicsense-backend**: Node.js & Express REST API, JWT auth, SLA priority engine
- **civicsense-prototype**: React (Vite) + Tailwind CSS, interactive GIS maps & multi-role dashboards
